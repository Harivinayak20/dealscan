# Free-Tool Distribution Kit

Tools to distribute: the free price-checker (`/price-checker`) and the embeddable widget (`/widget`). Both are free, no signup gates mentioned in-app copy - confirm current terms in `src/app/price-checker/page.tsx` / `src/app/widget/page.tsx` before submitting anywhere that asks about pricing/licensing.

## Submission targets (12)

Skip anything that sells placements or requires payment - all of the below are free/organic submission channels.

| # | Target | Submit | Blurb (tailor per site) |
|---|--------|--------|---------------------------|
| 1 | Product Hunt | Tool page (`/price-checker`) | "DealScan.dev - paste a used-car listing, get an instant deal score, fair-price range, and risk flags. Free, no signup." |
| 2 | AlternativeTo | Tool page | List DealScan.dev as a free alternative in the "car buying / valuation tools" category. |
| 3 | SaaSHub | Tool page | Free listing category submission for auto/valuation tools. |
| 4 | BetaList (if still pre-launch eligible) | Tool page | Only if DealScan.dev qualifies as "new" per their submission rules - check current criteria first. |

| 7 | Slickdeals forums (car-buying advice threads) | Tool page | Only in threads explicitly asking for deal-checking tools; follow forum self-promo rules. |

Note: this list intentionally stops short of 15 - the remaining slots (Product Hunt-style "best of" newsletters, niche automotive Slack/Discord communities) should be added once Hari confirms which communities he's already a member of, since cold-joining a community solely to post a link reads as spam and risks bans.
