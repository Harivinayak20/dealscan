# DealScan Link-Building Kit

Ready-to-execute outreach kit. No invented statistics, no purchased links, no reciprocal schemes. Everything below cites only real DealScan assets and real, checkable facts.

## Linkable assets to promote

- `/widget` — free embeddable used-car deal checker widget (iframe, one line of code)
- `/best` — best used cars hub (model roundups with reasons)
- `/fees/states` — dealer fees by state (50-state reference, doc fee caps, sales tax)
- `/cars` — buyer checks by model

## 1. Prospect list format

Track prospects in a spreadsheet with these columns:

| Column | Notes |
|---|---|
| `Prospect name` | Site or person |
| `URL` | Specific page you're pitching, not just homepage |
| `Contact` | Email or contact form link |
| `Category` | Credit union / finance blogger / resource page / journalist |
| `Target DealScan page` | `/widget`, `/best`, `/fees/states`, or `/cars` |
| `Pitch sent date` | |
| `Template used` | 1-4, see below |
| `Follow-up date` | pitch date + 5 business days |
| `Status` | Not sent / Sent / Replied / Link acquired / Declined |
| `Link acquired URL` | Fill in once live |

Build the actual 25 prospects by searching:
- `"auto loan calculator" credit union site:*.org` and `"member resources" auto loan credit union`
- `"car buying" OR "auto loan" personal finance blog "guest post" OR "resources"`
- `intitle:"resources" OR intitle:"useful links" "used car buying"`
- `intitle:"resources" "car buying tips"` (resource-page targets)

Do not fabricate names or DA numbers in the sheet — leave blank until you've actually looked the prospect up.

## 3. Weekly cadence (~2 hours/week, sustainable)

- **30 min** — find 5 new prospects (resource pages, blogs, credit unions) using the search queries above; add to sheet
- **45 min** — send 5 personalized pitches using templates 1-3, one custom line each referencing the actual page
- **30 min** — check HARO-successor platform (Connectively, Qwoted, Featured) for 3-5 relevant queries, answer with Template 4
- **15 min** — follow up once on pitches sent 5+ business days ago with no reply (never more than one follow-up)

Monthly: review Google Search Console → Links report for new referring domains and check for unlinked brand mentions via `"DealScan" -site:dealscan.dev`.

## 4. Unlinked-mention search queries

Run these monthly:

- `"DealScan" -site:dealscan.dev`
- `"DealScan.dev" -site:dealscan.dev`
- `"dealscan" used car -site:dealscan.dev`

For any hit that names DealScan without linking, send a short note: "Thanks for mentioning DealScan — would you mind linking to dealscan.dev so readers can find it?" This tactic has the highest conversion rate of any outreach type, so prioritize it over cold pitches.
